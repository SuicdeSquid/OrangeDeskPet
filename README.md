# OrangeDeskPet

一只完全离线运行的 Windows 桌面宠物小橘，支持透明动画、随机行为、自由放置和多档缩放。

## 下载

请前往 [OrangeDeskPet V5 Release](https://github.com/SuicdeSquid/OrangeDeskPet/releases/tag/v5.0.0)，下载 **XiaojuDeskPet-v5-win-x64.zip**。

下载后请完整解压，再运行文件夹中的桌面宠物程序。不要只复制 exe 文件，否则程序可能缺少动画资源。

## V5 功能

- 2 分钟无互动后自动进入休息状态
- 侧躺、仰面朝天、背身蜷缩、正面农民蹲四种休息姿态等概率出现
- 休息后保持姿态，点击小橘才会唤醒
- 唤醒后随机出现正面舔毛、打哈欠或背面舔毛，再衔接吃饭动作
- 长时间保持不动后，短暂眨眼和摇尾巴
- 支持 25%、50% 等尺寸选项
- 可放在桌面上的任意水平面

## 系统要求

- Windows 10/11，64 位
- 无需联网
